PETUNJUK MENJALANKAN WIREFRAME KOMPETISI LABBBAIK

ISI FOLDER:
- index.html : struktur/isi halaman website
- style.css  : tampilan wireframe, ukuran, jarak, dan warna abu-abu
- script.js  : interaksi sederhana untuk menu dan filter

CARA MEMBUKA:
1. Ekstrak file ZIP.
2. Buka VS Code.
3. Pilih File > Open Folder.
4. Pilih folder website-wireframe-mtq.
5. Klik kanan index.html > Open with Live Server.

CATATAN:
Ini adalah wireframe sederhana untuk halaman Kompetisi MTQ, bukan desain final.
Kotak abu-abu merupakan tempat gambar/logo/poster yang bisa diganti saat tahap desain final.
Ketiga file harus tetap berada di dalam folder yang sama.
